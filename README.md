# Brimbelle releases

Firmware releases for Brimbelle, a mono connected speaker (ESP32-S3,
Sonocotta Amped-ESP32). Each release carries `brimbelle.bin` (OTA image,
installed from the speaker's own web page) and `brimbelle-flash.zip` (first
flash over USB: unzip and run `flash.sh`, or use the web flasher under
`tools/web-flasher/`).
