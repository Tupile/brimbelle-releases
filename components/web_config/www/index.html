Status

Playback

Wi-Fi

Networks in order of preference. Leave the password blank to keep the stored one. Saving reboots the speaker.

Speaker

The name applies after a reboot. Pause limit: a pause longer than this many minutes stops playback (0 = never).

Sound correction

Up to 6 filters applied to everything that plays: type, frequency (Hz), gain (dB, -12 to 12) and width (Q). A high-pass cuts below its frequency and ignores the gain. A boost lowers the overall level by as much, so the speaker never plays louder. No filter means no correction.

Home Assistant (MQTT)

The knob appears in Home Assistant as a button event. Leave the password blank to keep the stored one. An empty URL turns MQTT off.

Web radios

Name, stream URL (http or https, .m3u/.pls accepted). "Decoy" opens a throwaway connection first for stations that inject a pre-roll ad.

Password

Protects this page. Empty removes it.
